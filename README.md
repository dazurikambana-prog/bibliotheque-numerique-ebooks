# LibraNum — Bibliothèque numérique

Site de démonstration d'une bibliothèque numérique pour la vente d'ebooks.

## Fonctionnalités

- Catalogue d'ebooks avec filtres (catégorie, tri, recherche)
- Fiches détail des livres
- Panier (stocké en localStorage)
- Design moderne et responsive
- Interface 100 % en français

## Déploiement

Site statique — compatible avec Vercel, Netlify, GitHub Pages, etc.

## Démonstration

Aucun paiement réel n'est effectué. Le panier et le checkout sont purement illustratifs.
